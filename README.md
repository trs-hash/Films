# Films — taras.kyiv.ua

Статичний сайт (GitHub Pages, домен у `CNAME`).

## Формат: сезони

Один сезон — одна велика тема, нова серія щотижня.

| Файл | Що це |
|---|---|
| `index.html` | Головна: сезони та їхні серії |
| `seasons.json` | Опис сезонів — **єдине, що треба редагувати руками** |
| `state.json` | Режим: `youtube` (жива стрічка з API) або `doomsday` (лише `archive.json`) |
| `archive.json` | Локальний архів (фолбек, коли YouTube недоступний) |
| `calendar.html` | Збережений старий макет — календарна «стіна днів» |

### seasons.json

```json
{
  "seasons": [
    {
      "n": 1,
      "title": "Назва теми сезону",
      "about": "Кілька речень про тему.",
      "start": "2026-09-20",
      "end": "2026-12-20",
      "schedule": "Нова серія щонеділі",
      "playlist": "PLV5Ekm-F8nm4",
      "episodes": null,
      "support": ""
    }
  ]
}
```

- `n` — номер сезону; `start`/`end` — дати `РРРР-ММ-ДД`. За ними сайт сам вирішує:
  до старту — «Скоро» (анонс), між датами — «Зараз», після — «Завершено».
- `title` порожній → заголовком буде «Сезон N». `about` — опис теми (переноси рядків зберігаються).
- `playlist` — ID плейлиста сезону на YouTube. **Серії сезону = відео з цього плейлиста.**
  Приватні / заплановані відео не показуються, доки не стануть публічними.
- `episodes` — скільки серій заплановано (необовʼязково): тоді прогрес «Серій: 2 / 10»
  і пунктирне місце «наступна серія» зникне, коли всі вийдуть.
- `schedule` — вільний текст про ритм виходу. `support` — посилання «Підтримати сезон»
  (напр. mono-банка); порожнє → кнопки нема.
- Новий сезон = новий обʼєкт у масиві (порядок не важливий).

Опис відео на YouTube — це записка під плеєром (як і раніше): символ `№` (не «№5»)
позначає важливу серію червоною зірочкою, штамп `🕒 ГГ:ХХ ДД/ММ/РРРР` стає підписом.

У режимі `doomsday` серії беруться з `archive.json` і розкладаються по сезонах за датами `start…end`.

## Повернутися до календаря

`calendar.html` — точна копія календарної головної (до 29.09.2026), доступна на `/calendar.html`.
Щоб повернути її на головну: скопіювати `calendar.html` поверх `index.html`
і прибрати з нього рядок `<meta name="robots" content="noindex">`.
Та сама версія є в історії git (коміт `b9cbb7d`).
