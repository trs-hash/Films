Privacy Policy

Autoposter101 · Last updated 30 July 2026

Autoposter101 is a private, single-user tool operated by Taras Maksymiak. It publishes short videos to one TikTok account — the account of the operator. It is not offered to the public, has no user registration, and serves no other people's accounts.

What this tool accesses

After you authorise the app through TikTok's standard login screen, it receives and uses:

  • An access token and a refresh token for the authorised TikTok account, used to upload and publish videos.
  • Basic account information — TikTok open ID, display name (nickname), and avatar URL — returned by the user.info.basic scope, used only to confirm that the correct account is connected.
  • Video files and their captions, prepared on the operator's own server and sent to TikTok for publication under the video.publish and video.upload scopes.

Where the data is stored

Tokens are stored in a configuration file on a private home server owned by the operator and located in Ukraine. The server is not publicly reachable; access is restricted to the operator. Video files are stored on the same server and in the operator's own private cloud storage before upload. Data is not shared with any third party.

What is never done with the data

  • TikTok data is never sold, rented, or shared with advertisers or data brokers.
  • TikTok data is never used to train, fine-tune, or evaluate any AI or machine-learning model.
  • No analytics, tracking pixels, or third-party trackers are used.
  • No data belonging to any other TikTok user is collected, requested, or processed.

Third-party services

To prepare its own videos before publication, the operator's server may use speech transcription and text-processing services. These services only ever receive audio and text from the operator's own videos being prepared; they never receive TikTok tokens, TikTok account information, or any other TikTok data. Amazon S3 is used as temporary storage for the operator's own video files during upload.

Retention and deletion

Tokens are kept only while the integration is in use. Authorisation can be withdrawn at any time from TikTok under Settings and privacy → Security and permissions → Apps and services, which immediately invalidates the tokens. On withdrawal, the stored tokens are deleted from the server. To request deletion of any data held about the connected account, contact the address below.
