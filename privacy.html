Privacy Policy

Autoposter101 · Last updated 29 July 2026

Autoposter101 is a private, single-user tool operated by Taras Maksymiak. It publishes short videos to one TikTok account — the account of the operator — on a schedule. It is not offered to the public, has no user registration, and serves no other people's accounts.

What this tool accesses

After you authorise the app through TikTok's standard login screen, it receives and uses:

  • An access token and a refresh token for the authorised TikTok account, used to upload and publish videos.
  • Basic account information (TikTok open ID, display name, avatar URL) returned by the user.info.basic scope, used only to confirm that the correct account is connected.
  • Video files and their captions, prepared on the operator's own server and sent to TikTok for publication under the video.publish scope.

Where the data is stored

Tokens are stored in a configuration file on a private home server owned by the operator and located in Ukraine. The server is not publicly reachable; access is restricted to the operator. Video files are stored on the same server and in the operator's own private cloud storage before upload.

What is never done with the data

  • Nothing is sold, rented, or shared with advertisers or data brokers.
  • No analytics, tracking pixels, or third-party trackers are used.
  • No data belonging to any other TikTok user is collected, requested, or processed.

Third-party services

To prepare videos before publication, the tool uses OpenAI (speech transcription) and Anthropic (selecting moments for a clip). These services receive audio and text from the videos being prepared. They do not receive TikTok tokens or account information. Amazon S3 is used as temporary storage for video files during upload.

Retention and deletion

Tokens are kept only while the integration is in use. Authorisation can be withdrawn at any time from TikTok under Settings and privacy → Security and permissions → Apps and services, which immediately invalidates the tokens. On withdrawal, the stored tokens are deleted from the server.
